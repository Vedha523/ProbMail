χ² = Σ [ (O_i - E_i)² / E_i ]   •   P(Spam | Feature) = [ P(Feature | Spam) × P(Spam) ] / P(Feature)
Chi-Square (χ²) Feature Selection: Evaluates the independence between word occurrence and email classification. A high χ² statistic and p < 0.05 confirm that the word does not appear by random chance and is a statistically significant indicator.
Multinomial Naive Bayes: Combines prior class probability with token likelihoods using Laplace additive smoothing (α=1.0) to compute posterior probabilities.
Dataset: Trained on 1,500 curated Enron corpus emails (900 Ham, 600 Spam). Click the download button above to inspect the raw CSV file.

🛡️ Confusion Matrix & Classification Error Analysis

Type I Error: False Positives (FP)

{{ eval_metrics.confusion_matrix.false_positive }}

Legitimate emails incorrectly flagged as Spam. In email filtering, this is the most critical error to minimize, as users could miss important work contracts, academic notices, or personal messages.

Type II Error: False Negatives (FN)

{{ eval_metrics.confusion_matrix.false_negative }}

Spam emails missed and delivered to Inbox. While undesirable, this is less damaging than a Type I error. High recall reduces Type II errors to keep the inbox clean.
