📐 Academic Foundation: Bayes' Theorem & Conditional Probability
P(Spam | X) = [ P(X | Spam) × P(Spam) ] / P(X)   |   P(Ham | X) = [ P(X | Ham) × P(Ham) ] / P(X)
Each incoming email is decomposed into features X = {w₁, w₂, ... wₙ}. Using the Naive Bayes conditional independence assumption and Laplace smoothing (α=1.0), the engine calculates the posterior probability that the message is Spam or Ham. Chi-square (χ²) statistical testing isolates features with p < 0.05 significance.
